# Стол тенниси — 2 оюнчу

Бир компьютерде эки адам ойной турган толук версия.

1-Оюнчу (сол жак): W = өйдө, S = ылдый
2-Оюнчу (оң жак): ↑ = өйдө, ↓ = ылдый

Биринчи болуп 11 упай алган оюнчу жеңет. Топтун багыты соккунун жерине жараша өзгөрөт жана ар бир соккудан кийин ылдамдыгы жогорулайт.

Иштетүү: ZIP архивди чыгарып, index.html файлын Chrome/Edge/Firefox менен ачыңыз. Интернет талап кылынбайт.
